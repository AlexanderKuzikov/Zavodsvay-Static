## 2026-05-22: PHP file-router вместо SSG

**Контекст:** Нужен production-сайт без серверной логики на хостинге.

**Решение:** PHP для разработки (include-based), статика для деплоя.

**Альтернативы:** Next.js, Hugo, чистый HTML.

**Trade-off:** Нет hot-reload, но zero-dependency на продакшене.

## 2026-05-22: Yandex Maps v3 + JSON данные

**Контекст:** 500+ объектов на карте выполненных работ.

**Решение:** Yandex Maps JS API v3, данные в JSON (data/objects/).

**Альтернативы:** MapLibre + PMTiles (в WebForge), Google Maps.

**Trade-off:** Зависимость от Yandex API, но бесплатно и быстро для РФ.

## 2026-08-19: Обратный звонок — mail() на хостинге

**Контекст:** Нужна кнопка «Обратный звонок» с уведомлением на stas@zavodsvay.ru.

**Решение:** POST-эндпоинт `/callback/` на PHP-роутере, отправка через `mail()` с
From `webmaster@zavodsvay.ru` (совпадение домена → лучшая доставляемость).
Анти-спам: honeypot + rate-limit (сессия 120 с, файловый лог IP 5/сутки).
Модалка в partials, кнопка — широкая в сайдбаре под иконками мессенджеров.

**Альтернативы:** SMTP (Gmail app password — чужой From, лимиты), внешние форм-сервисы
(зависимость от третьей стороны в РФ), только ссылка на телефон (не даёт заявку).

**Trade-off:** `mail()` зависит от настроек MTA хостинга (ISPmanager) — проверить после
деплоя; если письма не приходят, fallback на SMTP. Лог лидов в `data/leads-callback.log`
одновременно служит резервной копией заявок.

## 2026-09-11: Обратный звонок — SMTP primary (fallback сработал)

**Контекст:** `mail()` на проде принимал письма и молча терял их по дороге к MX
(kompleks-s.ru отбивает 550 на несуществующего конвертного отправителя).
Форма при этом показывала успех — заявки терялись с улыбкой.

**Решение:** отправка через SMTP/SSL напрямую на kompleks-s.ru:465 с авторизацией
служебным ящиком (конверт = существующий ящик → проходит sender verification);
`mail()` оставлен как fallback. SMTP-клиент — ~70 строк без зависимостей
(composer на шареде нет), этапы падений пишутся в `error_log`.
Пароль — только в `<home>/callback-smtp-config.php` (вне webroot, вне git;
репо публичное), залит по FTP вручную. Попутно: починен IP-лимит 5/сутки
(искал IP не в том поле), MIME-кодировка кириллической темы, санитизация
телефона от инъекции заголовков, ротация лога, `.htaccess` закрыл `.log`.

**Альтернативы:** чинить MTA хостинга через поддержку (чужая зона, негарантированный
срок), PHPMailer (зависимость ради одной формы).

**Trade-off:** пароль вне репо — ротация вручную; исходящий 465 должен быть открыт
на хостинге (проверяется живым тестом после деплоя).

## 2026-09-15: Обратный звонок — отправитель mail.ru (победа)

**Контекст:** направление «хостинг → kompleks-s.ru» мёртво на любых портах
(destination-based фильтр, тикет без ответа), а `smtp.mail.ru:465/587`
с хостинга открыт. Попытка использовать mapcontrol@exlibrum.ru упёрлась
в тариф biz.mail.ru (app-пароли для почты закрыты).

**Решение:** отдельный ящик gefestzavod@mail.ru отправителем через
`smtp.mail.ru`. Код обобщён: хост/логин/пароль берутся из закрытого конфига,
From совпадает с логином (требование mail.ru), Reply-To на несуществующий
ящик убран. Живой тест: заявка дошла в site@ за секунды, все поля корректны.

**Альтернативы:** ждать поддержку Webhost, менять тариф biz.mail.ru,
релей на Sat (порты открыты — запасной вариант), email API.

**Trade-off:** зависимость от бесплатного ящика mail.ru (лимиты отправки);
пароль вне репо — ротация вручную.
