Источник: снапшот + `localStorage svayaproekt.v1` от 2026-10-12. Проект открывается первым — это их «витрина».

## Паспорт

- Объект: `Жилой дом 8,0 × 6,0 м`; адрес: `Московская обл., г. Пушкино, СНТ «Рассвет», уч. 14`; заказчик: `Иванов И. И.`
- Организация: `ООО «Свайный двор»`, `+7 (900) 000-00-00`; чертёж `ФС-001`, стадия `П`, дата `2026-10-12`.
- Оси X: `[0, 2000, 4000, 6000, 8000]` (база + 2 ряда-авто + 2 стены); оси Y: `[0, 1500, 3000, 4500, 6000]`.
- Сваи: пересечения `стена × всё`, `ряд × только пересечения` + сортировка сверху-вниз/слева-направо, нумерация 1–21. `overrides={}`, `extra=[]` (ручных правок нет).
- Дефолт сваи: `винтовая Ø108, 2500, оголовок 200×200, с оголовком`.
- Опции: `maxStep 2500, autoSplit on, dimMode axes, snap 50, лист A3, масштаб авто→1:50`.
- `fin`: монтаж вкл (цена null→из прайса), доставка 4500, обвязка выкл (`Швеллер 16П`), заполнение вкл (ПГС, 100%, мешок из прайса), скидка 0, НДС 0.
- `calc`: дом каркасный, 1 этаж, стены 3000, кровля металлочерепица, перекрытие деревянное, снег 180, грунт суглинок, промерзание 1400.
- `geo.off` (слои при этом заполнены!): насып 400 / суглинок мягкопл. 1600 / суглинок тугопл. 2000 / песок мелкий 3000; УГВ 2500, промерзание 1400, `gammaK = расчёт по таблицам СП`.
- `site`: цоколь 500, перепад 0, направление `x+`, укосины вкл (`Уголок 63×63×5`, лимит 600).
