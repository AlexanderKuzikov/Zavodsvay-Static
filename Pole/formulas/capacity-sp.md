# formulas/capacity-sp — несущая винтовой сваи по СП 24.13330 (CALC.capacity)

Дословная выдержка `function capacity(st, size, depthМм)` + `embedDepth` + `pickDepth` (шапка latter усечена лимитом — смысл зафиксирован).

## Глубина лопасти (embedDepth)

```
need = freeze + 500                       # ниже промерзания на 500 (СП 24 п.7.2, СП 22 — заглубление ниже расчётной глубины промерзания)
для каждого слабого слоя (bearing=false) с bottom > need:
    need = bottom + 500                   # проходим насквозь; note: 'пройден слабый слой ...'
L2 = layerAt(need); если !bearing: need = bottom+500
depth = ceil(need/100)*100
```

## Несущая (capacity)

```
D  = blade/1000               # диаметр лопасти, м (из SCREW[size].blade)
d0 = size/1000                # диаметр ствола, м
A  = π/4·D²                   # проекция лопасти
u  = π·d0                     # периметр ствола
al = alphaFor(phi)            # α1/α2 по ALPHA (табл. 7.9 СП 24 / табл. 8 СНиП 2.02.03-85); пара показывается в расчёте для проверки
c1 = слой.c                   # сцепление в рабочей зоне, кПа
g1 = средневзвешенный вес выше лопасти; ниже УГВ: g = max(8, g−10) (взвешивание водой)
fi = средневзвешенное f выше лопасти БЕЗ зоны d над лопастью (bot = min(bottom, depth−D))
gc = 0.8                       # коэфф. условий работы
Fd = gc·((a1·c1 + a2·g1·depth)·A + u·fi·max(0, depth−D))
gk = GAMMA_K[gammaK]           # 1.4 / 1.25 / 1.2
N (кН) = Fd/gk;  NkG (кг) = Fd/gk/9.81·1000
```

Возврат: `{Fd, gk, N, NkG, alpha, c1, g1, fi, A, u, depth, D, layer, gc, embed}`.

## Подбор глубины (pickDepth)

Опускает лопасть шагами, пока `Fd/γk` не перекроет нагрузку на сваю, либо пока не упрётся в длину ствола 6 м. (Тело функции — beyond снятого фрагмента; зафиксировать при повторном доступе.)

## Применение

`byGeo = geo.on && kind==screw`. При `byGeo` несущая каждой опции — из `capacity`, иначе — из типовой `loadPerPile`. Проектный алгоритм ссылается на СП 24.13330, табл. 7.3 (f) и 7.9 (α1/α2). Для наших калькуляторов: коэффициенты и таблицы — сверить с актуальным СП 24.13330.2021, результат считать предварительным (требуются ИГИ/испытания — так пишет и сам СССФР).
