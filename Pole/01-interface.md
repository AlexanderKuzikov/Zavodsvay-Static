## Левая колонка (параметры)

1. **Шаблон объекта.** Чипы: `Дом 8×6`, `Дом 9×6`, `Дом 9×9`, `Баня 6×4`, `Терраса 6×3`, `Забор 12 м`, `ЖБ сваи 6×6`. Подпись: «Шаблон задаёт габариты, оси и типоразмер свай. Дальше всё правится вручную».
2. **Оси и габариты.**
   - `Шаг свай в ряду, не более` = 2500 + кнопка `Разбить по шагу`.
   - Чекбокс `Добивать оси рядов автоматически` (вкл).
   - `Габариты задаются`: `по осям свай` / `по наружной грани дома` (при переключении — поле привязки `inset`, по умолчанию 75 мм).
   - Списки осей: цифровые по X (`1 база 0 [стена]`, `1/1 2000 [ряд, авто]`, `2 2000→4000 [стена]` … всего 5: 0/2000/4000/6000/8000) и буквенные по Y (`А база`, `А/1 1500`, `Б 1500→3000`, `Б/1`, `В →6000`). У каждой: тип `стена/ряд`, кнопка `×`, признак `авто` (добавлена по шагу).
   - Правило: «Стена» — сваи по всей длине; «Ряд» — только пересечения с основными. Оси таскаются мышью на чертеже, `Alt` — сохранить габарит.
3. **Свая по умолчанию.** Тип `Винтовая/Железобетонная`; ствол `Ø76/89/108/133`; длина 1.5–6.0 шаг 0.5 (дефолт 2.5 м); цена изделия `3 450 ₽`; оголовок (`Без`, `150×150 — 340`, `200×200 — 400` выбрано, `250×250 — 520`); подсказка `брус, бревно, каркас в 2 этажа · ≈5,0 т/сваю`; кнопки `Применить ко всем сваям` / `Сбросить изменения`.
4. **Выделенные сваи (0).** «Клик — выделить, Shift — несколько, рамкой — группу». Кнопки `Выделить все / Выделить изменённые`.
5. **Калькулятор нагрузок.** Селекты: дом (`Каркасный/СИП` выбран; брус 150/200; бревно; газобетон 300/400; кирпич 250; навес/забор), этажи, высота стен, перекрытие (`деревянное` выбрано; ж/б плита; по грунту), кровля (`металлочерепица` выбрана; профлист; мягкая; ондулин; керамика; без кровли), снег (`I(80)…VI(400)`, выбран `III — Москва, МО (180)`), грунт (`песок средний/супесь/суглинок базовый выбран/глина/насыпной-торф`), промерзание.
6. **Геологические изыскания.** Тумблер `on/off` (по умолчанию off — считается по типовой таблице; при on — по СП с `gammaK`); способ определения несущей (`таблицы СП` / `зондирование` / `испытания свай`); скважина, УГВ, глубина промерзания; таблица слоёв (4 слоя в демо: насыпной 400 + суглинок мягкопл. 1600 + суглинок тугопл. 2000 + песок мелкий 3000).

8. **Материалы и масса.** Сводка: сваи винтовые 21 шт / 567 кг; оголовки 21 / 71 кг; всего 1 425 кг; транспорт `Газель, 1 рейс`; полость 1 сваи 20 л; объём 0.421 м³; +10% → 0.463 м³; ПГС 20 мешков × 40 кг; масса заполнения 787 кг. Подпись про внутренний диаметр `(Ø − 2×стенка)`.
