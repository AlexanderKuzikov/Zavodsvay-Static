Способ: DOM-разбор через браузер (снапшот, `localStorage`, выдержки inline-скрипта ~153 КБ). Бэкенда у страницы нет — весь расчёт в браузере.

> ⚠️ Повторное скачивание 12.10.2026 ~17:15 МСК не удалось: `sssfr.ru` не отвечает ни локально (TLS EOF / `ERR_CONNECTION_CLOSED`),

> При первой доступности сайта докачать: `Pole/original.html`, `favicon.svg`, `og.png`, шрифты. См. `SOURCES.md` и `assets/NOTES-assets.md`.

## Ключевые факты коротко

- Однофайловая SPA: HTML ~243 КБ, inline-CSS ~23+3.3 КБ, inline-JS ~153 КБ. Сеть после загрузки — только Яндекс.Метрика (ID 113043827).
- Модули `window`: `CATALOG` (прайсы/грунты), `MODEL` (оси/сваи/история), `CALC` (нагрузки/геология/материалы), `DRAW` (лист ГОСТ, SVG), `SPEC` (смета/CSV/КП), `PRINT` (печать/PDF).
- Состояние — JSON v2 в `localStorage svayaproekt.v1`: `meta/opts/defaults/axV/axH/overrides/extra/prices/rows/fin/calc/geo/site`.
- Экспорты: `.json`, PNG 2600px (canvas), SVG 1600px, CSV `;`, «Копировать КП», печать (лист чертежа + лист спецификации).
- Цены — среднерыночные по участникам сообщества, НЕ оферта. Несущая по СП — предварительная, СП 24.13330 требует полевых испытаний.

## Как использовать у нас (Гефест)

1. SSOT номенклатуры закрыть у себя (`data/calc/*.json`) — диаметры Гефеста (60/73/102/114) НЕ совпадают с СССФР (57/76/89/108/133).
2. Из `CALC` брать только методику (структуру `run/capacity/embedDepth/materials`), коэффициенты сверить с СП 24.13330 / СП 22.13330 / СП 20.13330.
3. Не копировать дизайн и тексты 1:1 — чужой продукт. См. дисклеймер сайта (ст. 437 ГК РФ).
