## Чего здесь НЕТ (не удалось снять)

- `original.html` целиком (243 КБ). Есть только снапшот + выдержки. При доступности — `curl`/браузером сохранить как есть.
- `favicon.svg` (https://sssfr.ru/favicon.svg), `og.png` (https://sssfr.ru/og.png), `site.webmanifest`, `icon-180.png`.
- Шрифты — только ссылка Google Fonts (Golos Text / PT Sans Narrow / IBM Plex Mono), сами woff2 не качали (не нужно — у нас свои локальные шрифты).
- Полный текст inline-JS: сняты все таблицы и ключевые функции, но не каждая строка UI-логики (рендер панелей, drag-and-drop). Для этого нужен `original.html`.
- Картинки объекта/схем: их нет как файлов — план рисуется кодом в SVG на лету.

## Достоверность

- JSON-таблицы в `data/` — дословно из кода (числа сверены с двумя независимыми выдержками: поиск `var NAME =` + `Object.keys`).
- Формулы в `formulas/` — дословные выдержки функций с указанием усечений. Где вывод обрезан лимитом — помечено `…/* усечено */`.
- Демо-цифры (`02-demo-project.md`) — из снапшота и `localStorage` одного и того же дефолтного проекта (21 свая, 8 000×6 000).
- Цены и несущие способности — справочные данные СССФР, не норматив и не наш прайс.

## Что сделать при повторном доступе

1. Сохранить `original.html` без модификаций.
2. Сохранить `favicon.svg`, `og.png`.
3. Снять `window.CATALOG.updated` (в коде есть поле — дату обновления прайса мы не зафиксировали).
4. Снять тексты подписок «Как работать», WhatsApp-номер обратной связи, тексты примечаний чертежа 1–5 (частично есть в снапшоте).
5. Проверить версии: `st.version` (было 2), новые пресеты/диаметры (сейчас max Ø133 в конструкторе, а в `/svai/` — до Ø325).
